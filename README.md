# УВМ: ассемблер и интерпретатор (вариант 26)

Python 3.10+, сторонние библиотеки не нужны.

## Язык ассемблера

Одна команда на строку: `мнемоника операнд, операнд`.
Комментарий начинается с `;`. Регистр: `r<N>`. Число: десятичное или `0x..`.
Мнемоники не зависят от регистра букв.

| Команда | Запись | A | Поля | Действие |
|---|---|---|---|---|
| Загрузка константы | `ldc r<C>, <B>` | 22 | B: 30 бит (5-34), C: 6 бит (35-40) | `reg[C] = B` |
| Чтение из памяти | `ld r<B>, <C>` | 0 | B: 6 бит (5-10), C: 17 бит (11-27) | `reg[B] = mem[C]` |
| Запись в память | `st r<B>, r<C>` | 16 | B: 6 бит (5-10), C: 6 бит (11-16) | `mem[reg[B]] = reg[C]` |
| Циклический сдвиг вправо | `ror r<B>, <C>` | 4 | B: 6 бит (5-10), C: 17 бит (11-27) | `reg[B] = ror(reg[B], mem[C])` |

Размер команды 6 байт, A занимает биты 0-4.

## Запуск

В Linux вместо `python` используйте `python3` (или установите пакет `python-is-python3`).
Ассемблер (на этапе 1 режим `--test` печатает поля команд):

    python -m uvm.assembler examples/spec_tests.asm out.bin --test

Ожидаемый вывод:

    A=22, B=638, C=25
    A=0, B=10, C=28
    A=16, B=54, C=15
    A=4, B=55, C=454

## Интерпретатор

    python -m uvm.interpreter <бинарный файл> <дамп.json> --from <адрес> --to <адрес>

Выполняет программу и сохраняет дамп памяти данных в JSON. Диапазон адресов
включает оба конца. Формат дампа: объект `{"адрес": значение}`.

### Модель памяти

- Память команд хранит 6-байтовые команды из бинарного файла и отделена от памяти данных.
- Память данных: 131072 слова (адрес кодируется 17 битами поля C).
- Регистры: 64 штуки (номер кодируется 6 битами поля B или C).
- Слово: 32 бита, при записи значение обрезается до 32 бит.
- Обращение к адресу вне памяти завершает программу с ошибкой.

### Пример: копирование массива

    python -m uvm.assembler examples/copy_array.asm copy_array.bin
    python -m uvm.interpreter copy_array.bin dump.json --from 200 --to 204

Содержимое `dump.json`:

    {
      "200": 11,
      "201": 22,
      "202": 33,
      "203": 44,
      "204": 55
    }
